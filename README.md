# 慾望清單・冷靜期（DMS）v0.1 初版

衝動購物克星：依金額自動鎖定「確定購買」，冷靜期過後才能決定買或不買。
單一檔案 `index.html`，不需建置，直接放上 GitHub Pages 即可使用。

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `desire-list`）。
2. 上傳 `index.html`（和這份 README）到 repository 根目錄。
3. 進入 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main` / `/ (root)`，按 Save。
4. 約 1 分鐘後即可從 `https://<你的帳號>.github.io/desire-list/` 開啟。
5. 第一次開啟時設定主密碼。

> 本機測試：直接用 Chrome / Edge 打開 `index.html` 即可。若瀏覽器顯示「不支援加密」，改用
> `python3 -m http.server` 再開 `http://localhost:8000`。

## 與規格書的差異（刻意的初版取捨）

- **技術棧**：規格書寫 React / Next.js + Zustand + RxJS。初版改用單一 HTML + 原生 JavaScript，
  目的是本週可上線、零建置、GitHub Pages 直接部署。功能面一致，之後要遷移到 Next.js 時資料格式可沿用。
- **儲存**：密文同時寫入 IndexedDB 與 localStorage（互為備援），規格書是依資料量分流。

## 注意事項

- 資料只存在「這個瀏覽器」。換電腦、換瀏覽器或清除網站資料前，請先到「設定 → 匯出加密備份」。
- 主密碼無法找回；忘記只能清除重來（可用備份還原，但需要建立備份時的密碼）。
- 前端門禁保護的是「資料內容」，網頁程式碼本身在公開 repo 中是看得到的，這是靜態託管的正常情況。
